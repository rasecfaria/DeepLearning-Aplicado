# DeepLearning-Aplicado

Repositório para a unidade curricular de DeepLearning Aplicado na universidade.

## Descrição

Este repositório contém os Jupyter Notebooks e materiais desenvolvidos durante o curso de DeepLearning Aplicado. O objetivo é organizar e documentar os exercícios práticos, projetos e experimentações realizadas ao longo da disciplina.

## Estrutura do Repositório

```
DeepLearning-Aplicado/
├── notebooks/          # Jupyter Notebooks organizados por tópico/aula
├── README.md          # Este arquivo
└── .gitignore         # Arquivos a serem ignorados pelo Git
```

## Pré-requisitos

Para executar os notebooks deste repositório, você precisará de:

- Python 3.7 ou superior
- Jupyter Notebook ou JupyterLab
- Bibliotecas de Deep Learning (serão especificadas em requirements.txt quando necessário)

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/rasecfaria/DeepLearning-Aplicado.git
   cd DeepLearning-Aplicado
   ```

2. (Opcional) Crie um ambiente virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # No Windows: venv\Scripts\activate
   ```

3. Instale as dependências (quando disponíveis):
   ```bash
   pip install -r requirements.txt
   ```

4. Inicie o Jupyter:
   ```bash
   jupyter notebook
   ```

## Como Usar

1. Navegue até a pasta `notebooks/`
2. Abra o notebook desejado
3. Execute as células sequencialmente
