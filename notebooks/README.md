# Notebooks

Este diretório contém os Jupyter Notebooks desenvolvidos durante a unidade curricular de DeepLearning Aplicado.

## Organização

Os notebooks estão organizados por tópico ou aula. Cada notebook deve incluir:

- Título descritivo
- Objetivos de aprendizagem
- Código bem comentado
- Visualizações quando apropriado
- Conclusões ou resultados

## Como usar

Para executar os notebooks:

1. Instale as dependências necessárias (ver requirements.txt na raiz do repositório)
2. Inicie o Jupyter Notebook ou JupyterLab:
   ```bash
   jupyter notebook
   ```
   ou
   ```bash
   jupyter lab
   ```
3. Navegue até o notebook desejado e abra-o

## Requisitos

- Python 3.7+
- Jupyter Notebook ou JupyterLab
- Bibliotecas de Deep Learning (TensorFlow, PyTorch, etc.)
